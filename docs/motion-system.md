# Motion system

Motion explains how a source idea becomes a usable component. It never blocks reading, navigation, or installation.

## Ownership

- CSS: local hover, focus, simple state, and fallback visuals.
- Motion: component transitions and springs. Native scroll updates chapter navigation only.
- Anime.js: isolated SVG paths and code-line sequences with explicit cleanup.
- React Three Fiber: the optional constellation canvas only.

No element may be driven by two engines. New animations must name their owner during review.

## Chapters

Signal assembles the four-diamond Interface Engine with Assemble, Explore, and Translate controls. Constellation expands it into geometric parts and filtered domain links. Translation switches between actual React, Vue, and Svelte Animated Tabs runtimes. Ownership reveals real source files and an available source-install command; npm remains unpublished. Open Orbit demonstrates Prompt Composer locally, then returns to creator provenance and contribution.

## Fallbacks

The server renders every heading, paragraph, link, command, and chapter miniature. The SVG/CSS constellation is visible before hydration and remains final for reduced motion, mobile, touch-constrained layouts, save-data, low-power detection, and canvas failure. The canvas is `aria-hidden` and no essential action occurs inside it.

## Performance budgets

Camera framing fits a reserved world-space envelope to the current canvas aspect ratio and invalidates demand rendering after resizing. Grid planes use buffered line segments rather than triangle wireframes. Geometry, source cards, and chapter slots remain separate layers. Chapter palettes apply locally to paper sections, the shared artboard, and sticky controls; scrolling does not recolor the entire story.

The hero scene stays in a normal-flow stage. Its placement, scale, palette, and mode are independent of scroll position. Anime.js runs its SVG timeline on its own clock; React Three Fiber runs local procedural motion. Play/Pause freezes those engines. Each later chapter owns an inline illustration; no canvas docks to chapter cards.

The canvas measures layout dimensions (`offsetSize: true`, `scroll: false`). ResizeObserver continues to handle real layout changes.

- No hero layout shift; the visual stage reserves its dimensions.
- Three.js stays outside the server and initial content path.
- One instanced node mesh, shared materials, and one buffered line network.
- Canvas rendering pauses when the story is off-screen or the page is hidden.
- Later chapters use content visibility where appropriate.
- Only requested previews load. Translation loads a Vue or Svelte runtime on demand after the visitor selects it.

Eligibility responds to the 981px breakpoint, reduced motion, save-data, available CPU hints, visibility, and context failure. Pause controls remain outside the decorative canvas. Each registry animation uses `observeMotion` (directly or through React's `useAnimation`) to stop when hidden, off-screen, paused, or reduced; it disconnects listeners on unmount.

Standalone Vue and Svelte previews are generated as separate Vite entry graphs. Each component is a dynamic chunk, mounted inside an iframe only on its framework route. Host controls cross the boundary through the documented preview protocol; pause uses a runtime-wide animation state and replay remounts the selected component.

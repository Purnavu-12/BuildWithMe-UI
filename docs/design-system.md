# Design system

BuildWithMe UI uses black, warm white, and neutral gray. Light and system themes preserve the same hierarchy. Meaning comes from brightness, scale, spacing, geometry, and type rather than framework colors.

Geist Sans carries interface and editorial text. Geist Mono carries coordinates, source paths, commands, counts, and technical annotations. Large headlines use tight tracking and controlled line length; body copy stays compact and readable. Fine borders, a restrained grid, orbital paths, and generous empty space connect the site surfaces.

The four-part brand mark represents one source idea and its three framework expressions. It appears as a small navigation mark and as the conceptual seed of Interface Cosmos. Do not replace it with framework logos in primary storytelling.

Components, catalog cards, documentation, empty states, and contribution flows use the same focus ring, neutral surfaces, border cadence, and type scale. Real previews carry visual interest. Hover and pointer depth are enhancements; labels, controls, and information remain complete without them.

Accessibility is a visual constraint. Maintain visible focus, AA contrast, 200% zoom, minimum touch targets, semantic headings, and a logical server-rendered reading order in both themes.

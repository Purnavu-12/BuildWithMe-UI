# Aurora field

Slow-moving color that gives a quiet page some atmosphere.

## Usage

```tsx
import AuroraField from '@/components/buildwithme/aurora-field/aurora-field';

<AuroraField />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

# Particle field

A deterministic constellation of gently drifting points.

## Usage

```tsx
import ParticleField from '@/components/buildwithme/particle-field/particle-field';

<ParticleField />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

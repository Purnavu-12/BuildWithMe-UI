# Flowing lines

A sequence of luminous lines, moving with a shared rhythm.

## Usage

```tsx
import FlowingLines from '@/components/buildwithme/flowing-lines/flowing-lines';

<FlowingLines />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

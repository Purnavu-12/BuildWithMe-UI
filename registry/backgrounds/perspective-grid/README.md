# Perspective grid

An infinite horizon, built from a few simple lines.

## Usage

```tsx
import PerspectiveGrid from '@/components/buildwithme/perspective-grid/perspective-grid';

<PerspectiveGrid />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

Original implementation by BuildWithMe-UI contributors. MIT.

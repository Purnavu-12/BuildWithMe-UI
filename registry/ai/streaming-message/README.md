# Streaming message

A local text-stream demonstration with a readable static fallback.

## Usage

```tsx
import StreamingMessage from '@/components/buildwithme/streaming-message/streaming-message';

<StreamingMessage />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

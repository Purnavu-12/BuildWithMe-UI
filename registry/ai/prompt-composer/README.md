# Prompt composer

A thoughtful starting point for a conversation with AI.

## Usage

```tsx
import PromptComposer from '@/components/buildwithme/prompt-composer/prompt-composer';

<PromptComposer />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

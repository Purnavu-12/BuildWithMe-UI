# Suggestion chips

Small invitations that make a blank canvas less blank.

## Usage

```tsx
import SuggestionChips from '@/components/buildwithme/suggestion-chips/suggestion-chips';

<SuggestionChips />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

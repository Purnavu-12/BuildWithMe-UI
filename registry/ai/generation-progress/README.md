# Generation progress

Clear progress through a deterministic generation sequence.

## Usage

```tsx
import GenerationProgress from '@/components/buildwithme/generation-progress/generation-progress';

<GenerationProgress />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

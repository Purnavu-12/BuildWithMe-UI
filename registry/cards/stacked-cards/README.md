# Stacked cards

A small deck of ideas. Shuffle to find your next one.

## Usage

```tsx
import StackedCards from '@/components/buildwithme/stacked-cards/stacked-cards';

<StackedCards />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

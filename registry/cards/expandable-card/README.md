# Expandable card

A compact card that makes room for the whole story.

## Usage

```tsx
import ExpandableCard from '@/components/buildwithme/expandable-card/expandable-card';

<ExpandableCard />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

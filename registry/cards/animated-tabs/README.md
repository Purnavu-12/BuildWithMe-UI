# Animated tabs

A sliding indicator with complete keyboard navigation.

## Usage

```tsx
import AnimatedTabs from '@/components/buildwithme/animated-tabs/animated-tabs';

<AnimatedTabs />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

# Spotlight card

A soft pool of light follows you across the surface.

## Usage

```tsx
import SpotlightCard from '@/components/buildwithme/spotlight-card/spotlight-card';

<SpotlightCard />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

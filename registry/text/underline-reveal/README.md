# Underline reveal

An expressive underline for the words that matter.

## Usage

```tsx
import UnderlineReveal from '@/components/buildwithme/underline-reveal/underline-reveal';

<UnderlineReveal />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

# Stagger reveal

Typography that arrives one word at a time.

## Usage

```tsx
import StaggerReveal from '@/components/buildwithme/stagger-reveal/stagger-reveal';

<StaggerReveal />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

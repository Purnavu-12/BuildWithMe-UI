# Magnetic button

A spring-loaded button that gently follows your pointer.

## Usage

```tsx
import MagneticButton from '@/components/buildwithme/magnetic-button/magnetic-button';

<MagneticButton />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

# Shimmer button

A quiet sweep of light across a beautifully simple action.

## Usage

```tsx
import ShimmerButton from '@/components/buildwithme/shimmer-button/shimmer-button';

<ShimmerButton />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

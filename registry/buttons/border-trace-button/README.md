# Border-trace button

A moving highlight that traces the edge of your next action.

## Usage

```tsx
import BorderTraceButton from '@/components/buildwithme/border-trace-button/border-trace-button';

<BorderTraceButton />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

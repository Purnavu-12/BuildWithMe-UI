# Press-depth button

A tactile, raised button with a satisfying press state.

## Usage

```tsx
import PressDepthButton from '@/components/buildwithme/press-depth-button/press-depth-button';

<PressDepthButton />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.

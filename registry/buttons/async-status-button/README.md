# Async-status button

Idle, working, and success states in one accessible action.

## Usage

```tsx
import AsyncStatusButton from '@/components/buildwithme/async-status-button/async-status-button';

<AsyncStatusButton />;
```

## Accessibility

Respects prefers-reduced-motion; pauses when off screen or the document is hidden. Interactive controls support keyboard focus. Use paused to stop the demonstration.
